# How to use
- Download and unzip the folder
- Run the command in terminal

​```
streamlit run your_dir\app.py
​```

- It will auto open the web app or click the link to view
- Choose Model to use
- Choose Target Word
- Enter Sentence
- Click Predict button and watch the result
